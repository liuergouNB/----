
## 怎么玩

用本地静态服务器打开（因为用了 ES Module，直接双击 html 可能被浏览器拦截）：

```bash
# 在项目文件夹里执行其一
npx --yes serve .
# 或
python -m http.server 8080
```

浏览器打开提示的地址（一般是 `http://localhost:3000` 或 `http://localhost:8080`）。

## 功能

- 双人对战 / 挑战 AI
- 移动、防御、跳跃、普攻、闪现、技能
- 游戏内键位映射（自动保存到浏览器）

## 默认键位

| 动作 | 玩家1 | 玩家2（可在设置里改） |
|------|-------|------------------------|
| 左/右 | A / D | ← / → |
| 防御 | S | ↓ |
| 跳跃 | G | ↑ |
| 普攻 | F | 小键盘 1 |
| 闪现 | H | 小键盘 2 |
| 技能 | R | 小键盘 3 |
